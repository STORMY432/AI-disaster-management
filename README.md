# 🌍 AI Disaster Management System

AI-powered disaster response assistant built with **React, FastAPI, LangChain, Ollama, and FAISS**.

## ✨ Features

* 🚨 Disaster classification
* ⚠️ Severity detection
* 📚 Retrieval-Augmented Generation (RAG)
* 🤖 Specialized disaster agents
* 💬 Context-aware conversations
* 📄 Source citations
* 🌦️ Weather integration (coming soon)
* 👁️ Vision AI (coming soon)

## 🛠️ Tech Stack

### Frontend

* React
* Axios

### Backend

* FastAPI
* LangChain
* Ollama
* FAISS

### AI Models

* Llama 3.2
* Nomic Embed Text

## 📂 Project Structure

```text
backend/
frontend/

```

## 🚀 Run Locally

### Backend

```bash
cd backend
uvicorn main:app --reload
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
